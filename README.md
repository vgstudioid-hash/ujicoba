# Be-ARISE Dashboard — GitHub Pages

Paket ini berisi versi website mandiri dari dashboard Be-ARISE. Tautan Virtual Asset 360 sudah diarahkan ke `VirtualTour/index.htm` dan memilih panorama sesuai kode aset melalui parameter `media-name`.

## Unggah dengan GitHub Desktop

1. Salin seluruh folder ini sebagai folder `dashboard` di root repositori `ujicoba`.
2. Salin folder `.github` dari paket ini ke root repositori (gabungkan jika sudah ada).
3. Commit dan push ke branch `main`.
4. Buka **Settings → Pages** dan pilih **Source: GitHub Actions**.
5. Setelah workflow selesai, buka `https://vgstudioid-hash.github.io/ujicoba/dashboard/`.

Jangan meletakkan folder `.github` di dalam `dashboard`; folder tersebut harus berada di root repositori.
